# حالة نقل أدوات Arsenal ATL إلى TypeScript

## البنية المنجزة

جميع الأدوات الثماني عشرة تملك الآن صفحة HTML مستقلة عند المسار النهائي `/tools/<slug>/` ونقطة دخول TypeScript خاصة بها. لا تستخدم هذه الصفحات iframe أو `toolLoader.js` أو صفحة تشغيل أم. نجح بناء Vite وTypeScript بعد إنشاء هذه البنية.

## الأدوات التي نُقل منطقها الوظيفي

| الأداة | الحالة | النطاق المنقول |
|---|---|---|
| مِصفاة النصوص | مكتمل أولياً | تنظيف، استخراج روابط وإيميلات، Base64، URL، نسخ |
| مقارنة النصوص | مكتمل أولياً | مقارنة الأسطر وعرض الإضافة والحذف |
| تشفير النصوص | مكتمل أولياً | AES-256-GCM وPBKDF2 محليان بصيغة `ARS1` جديدة |
| مولد QR | مكتمل أولياً | إنشاء Canvas وتنزيل PNG |
| ضاغط الصور | مكتمل أولياً | ضغط JPEG محلي بـ Canvas وتنزيل |
| معدل الصوت | مكتمل أولياً | تغيير السرعة والتصدير بصيغة WAV عبر Web Audio |
| ضاغط الفيديو | مكتمل أولياً | FFmpeg كسول، دقة/جودة/سرعة وتصدير MP4 |
| فيديو إلى صوت | مكتمل أولياً | FFmpeg كسول واستخراج MP3 |
| محول الصوت | مكتمل أولياً | FFmpeg كسول وتحويل MP3/WAV/OGG |
| محرر الصور | مكتمل أولياً | Canvas محلي: سطوع، تشبع، تدوير، قلب وتصدير JPG |
| الأرشفة والتشفير | مكتمل أولياً | اختيار ملفات وإنشاء ZIP مضغوط محلياً |
| إنشاء PDF | مكتمل أولياً | إنشاء A4 محلي من عنوان ونص عربي أو إنجليزي وتنزيل PDF |
| ضاغط PDF | مكتمل أولياً | إعادة حفظ محلية محسّنة وعرض فرق الحجم |
| محرر PDF | مكتمل أولياً | دمج ملفات PDF محلياً وفق ترتيب الاختيار |
| محرر الفيديو | مكتمل أولياً | قص مقطع محلي سريع أو دقيق باستخدام FFmpeg كسول |
| مزيل الخلفية | مكتمل أولياً | ONNX كسول في عامل مستقل، مع تصحيح يدوي وتصدير PNG شفاف |
| المشاركة المحلية | مكتمل أولياً | WebRTC مشفّر مع تبادل عرض/إجابة يدوي، من دون خادم وسيط |
| مزيل الضوضاء | مكتمل أولياً | ONNX كسول عند الطلب ومعالجة محلية وتصدير WAV |

## الأدوات ذات صفحة مستقلة

اكتمل نقل التطبيقات الأساسية للأدوات الثماني عشرة. تبقى اختبارات المتصفح الشاملة والتحسينات المقارنة مع النسخة المرجعية ضرورية قبل أي تسليم نهائي، ولا سيما لتدفقات ONNX وWebRTC التي تعتمد على موارد وشبكات خارجية عند أول استخدام.

## أداء الفيديو والتوافق

لا توجد ملفات FFmpeg WASM في المشروع. تُحمّل النواة من CDN عند أول عملية فيديو فقط. تستخدم صفحات Cloudflare التي تملك رؤوس العزل نواة متعددة الأنوية، بينما يستخدم التشغيل المحلي أو أي خادم بلا عزل النواة الأحادية المتوافقة. هذا يبقي المستودع صغيراً ويمنع تعطل الأداة محلياً.
