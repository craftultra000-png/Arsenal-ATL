# Slowed Studio Android

تطبيق Android Native مستقل مبني بـ Kotlin وJetpack Compose. لا يستخدم HTML أو JavaScript.

## الوظائف

- اختيار ملف صوتي محلي من Android Storage Access Framework.
- معاينة فورية مع تغيير السرعة من 0.50x إلى 1.50x من دون تغيير واجهة الصوت الأساسية.
- قص بداية ونهاية المقطع.
- تأثير Reverb مع Decay وMix.
- تصدير محلي إلى WAV أو MP3 بواسطة FFmpegKit.
- استخراج أفضل مسار صوتي من روابط YouTube العامة عبر NewPipe Extractor ثم تنزيله محليًا.
- تنزيل روابط الوسائط المباشرة عبر OkHttp.
- واجهة Flat مستوحاة من Windows 10: ألوان صلبة، حدود خفيفة، أزرار مستوية، بلا ضبابية أو بطاقات زجاجية.

## حدود المصادر

لا يوجد موصل رسمي عام ثابت لتنزيل Instagram داخل المشروع. لذلك يدعم الإصدار الأول الروابط المباشرة، بينما تبقى موصلات المنصات الأخرى منفصلة وقابلة للإضافة دون المساس بمحرك الصوت. يجب استخدام الملفات والروابط التي يملك المستخدم حق تنزيلها، مع الالتزام بشروط كل منصة.

## البناء

افتح هذا المجلد في Android Studio أو ابنِه من Termux بعد توفر JDK 17 وAndroid SDK:

```bash
./gradlew :app:assembleDebug
```

FFmpegKit Full GPL يزيد حجم التطبيق ويتطلب مراجعة التزامات GPL قبل أي توزيع تجاري.
